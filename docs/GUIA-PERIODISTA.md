# Guía rápida — Periodista / Encargado de contenido (1 página)

> Meta: publicar una noticia en **<2 minutos** sin llamar al informático.

## Hoy (Fase 1, sin CMS)
1. Abre `src/lib/content.ts` en GitHub (o pide acceso).
2. Copia un bloque `news` y cambia `title / date / category / excerpt`.
3. Click **Commit** → la web se actualiza sola en Vercel (1-2 min).
4. PDF nuevo: súbelo a `public/docs/` y agrega línea en `documents`.

## Fase 2 (Sanity, cuando se conecte)
1. Entra a `https://cbrb.sanity.studio` (usuario @cbrb.cl).
2. **Noticias → Nuevo** → Título, Foto, Fecha, Categoría, Texto → **Publicar**.
3. **Transparencia → Nuevo** → Título, Categoría, Año, Sube PDF → Publicar.
4. Listo. Sin código, sin GitHub.

## Reglas
- Foto horizontal 1200x800, <500 KB.
- Título corto (<70 caracteres), texto simple, sin mayúsculas gritadas.
- Fecha siempre `AAAA-MM-DD`.
- Si dudas: deja borrador y avisa al admin. No publiques sin revisar.
