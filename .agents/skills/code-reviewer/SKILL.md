## TypeScript Security Review (absorbido de typescript-security-review)

### Buscar en cada review:
1. **Secrets exposure**: API keys, tokens, passwords hardcodeados
2. **XSS**: `dangerouslySetInnerHTML` sin sanitizacion, datos de usuario renderizados sin escape
3. **SQL injection**: Queries concatenadas, falta de parametrizacion
4. **CSRF**: Endpoints mutables sin proteccion
5. **JWT/OAuth2**: Tokens en localStorage, falta de validacion, expiracion incorrecta
6. **Dependency CVEs**: Vulnerabilidades conocidas en dependencias
7. **RLS bypass**: Queries Supabase sin filtro `school_id`
8. **console.log de datos sensibles**: Debe usar `devLog()`/`devError()` en su lugar

### Patrones inseguros COMUNES en SIGCE:
```typescript
// MAL — sin filtro school_id
const { data } = await supabase.from('v7_students').select('*')

// BIEN
const { data } = await supabase.from('v7_students').select('*').eq('school_id', schoolId)
```
